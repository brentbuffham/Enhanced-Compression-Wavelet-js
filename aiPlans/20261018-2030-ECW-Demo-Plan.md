# ECW Demo Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A drag-and-drop browser demo for ecw-js (local and GitHub Pages) with progress, stats, a block-size map and a tabbed side panel driving every library function.

**Architecture:** Static vanilla page in `examples/browser/`; a module Worker (`demoWorker.js`) wraps a pure, Node-testable core (`lib/demoCore.js`) that reads through `BlobSource`; the UI only renders. Prerequisite: Plan 2 (`aiPlans/20261018-2012-ECW-Codec-Plan.md`) Tasks 1–3.

**Tech Stack:** Vanilla JS ES modules, Canvas 2D, module Workers, `node --test`.

**Spec:** `docs/superpowers/specs/2026-10-18-ecw-demo-design.md`

## Global Constraints

Plan 1 Global Constraints apply (zero deps, test-first for logic, style, no private data in git, commit per task to `main`). Demo code is not shipped (`files` whitelist).

## Review Focus

1. **Multi-GB files** — never read the whole file or whole index; a level's index slice is read once per level, blocks on demand.
2. **Non-ECW drop** — the error code and message show in the status bar; the page stays usable for the next drop.
3. **Dropping a second file mid-scan** — the old worker job is cancelled (worker terminated) before the new one starts.
4. **Huge levels** — a block map wider than the viewer still renders (one pixel per block, canvas scaled), and colour scaling ignores empty levels.
5. **Path traversal on the dev server** — `/../` requests are refused with 403.

**Files:** Create `_dev/serve.mjs`, `_dev/serveCore.mjs`; Test `test/dev/serveCore.test.js`; Modify `package.json` (script `demo`).

### Task 3: Demo core (worker logic, Node-testable)

**Files:** Create `examples/browser/lib/demoCore.js`, `examples/browser/lib/colorScale.js`, `examples/browser/lib/viewMath.js`; Test `test/examples/demoCore.test.js`, `test/examples/colorScale.test.js`, `test/examples/viewMath.test.js`.

**Interfaces:**
- `openFile(blob, onProgress) → Promise<{ info, index, grid, fileSize, stats: { compressionRatio, blockCount } }>` — `compressionRatio = width * height * bands / fileSize`.
- `readLevelBlockSizes(blob, index, grid, level, onProgress) → Promise<{ cols, rows, sizes: Uint32Array }>` — one read of the level's `cols * rows + 1` index entries.
- `inspectBlock(blob, index, grid, info, n) → Promise<{ n, level, row, col, start, end, streams: [{ band, subband, mode, length }] }>`.
- `sampleModes(blob, index, grid, info, level, count, onProgress) → Promise<{ sampled, modes: { 2, 5, 6 }, emptyShare }>` — evenly spaced blocks.
- `colorScale.js`: `blockSizeColor(size, minLog, maxLog) → [r, g, b]` (log scale, dark→bright), `sizeRange(sizes) → { minLog, maxLog }` ignoring zeros.
- `viewMath.js`: `screenToMap(view, sx, sy)`, `mapToScreen(view, x, y)` for a `view = { bounds, width, height, scale, offsetX, offsetY }`.
- Tests use `buildEcwFile` from Plan 2 Task 1 wrapped in a `Blob`.

- [ ] Tests first for each export (synthetic 3-level file: ratio, level sizes equal block lengths, inspectBlock stream labels/modes, sampleModes counts; colour endpoints and monotonic; map↔screen round trip) — FAIL; implement — PASS; commit `feat(demo): worker core, colour scale and view maths`.

### Task 4: Demo UI

**Files:** Create `examples/browser/index.html`, `demo.css`, `demo.js`, `demoWorker.js`, `viewer.js`, `panel.js`, `examples/browser/README.md` (manual checklist).

- Worker protocol: in `{ id, type: "open" | "levelBlocks" | "inspect" | "sample", payload }`; out `{ id, type: "progress", fraction, label }`, `{ id, type: "result", result }`, `{ id, type: "error", code, message }`. Typed arrays transferred. A new drop terminates and recreates the worker.
- Viewer: canvas, wheel zoom, drag pan, level picker; draws the block map (one pixel per block, nearest-neighbour scaled); polygon tool for the Clip tab.
- Panel tabs Info / Blocks / Clip / Read per spec §5, each with a "How it works" code box.
- Status bar: progress bar + headline stats.

- [ ] Build; run the manual checklist against the private sample on `npm run demo`; commit `feat(demo): drag-and-drop ECW workbench`.
